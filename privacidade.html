Política de privacidade

Esta é uma estrutura inicial e deve ser adaptada aos tratamentos de dados efetivamente usados pela loja.

Dados recolhidos

Durante uma compra podem ser tratados dados necessários para pagamento, faturação, entrega e apoio ao cliente.

Pagamentos

Os dados de pagamento são tratados pelo fornecedor de pagamentos integrado no checkout, de acordo com as respetivas políticas.

Cookies

O carrinho utiliza armazenamento local do navegador para manter os produtos selecionados. Adiciona aqui a política de cookies aplicável ao teu site.

Direitos

Os titulares dos dados podem exercer os direitos previstos na legislação de proteção de dados através dos contactos oficiais da empresa.
